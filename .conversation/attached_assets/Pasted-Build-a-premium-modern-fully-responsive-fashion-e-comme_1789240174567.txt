Build a premium, modern, fully responsive fashion e-commerce website for a clothing brand called **DIRACE**.

The website should feel like a real contemporary fashion brand — clean, bold, minimal, editorial, and premium. Avoid the appearance of a generic Shopify template.

## BRAND

Brand name: DIRACE

Brand positioning:
DIRACE is a modern fashion/clothing brand focused on stylish, high-quality clothing with a strong contemporary identity.

Design direction:

* Premium
* Minimal
* Fashion-forward
* Editorial
* Bold typography
* Clean layouts
* High-quality imagery
* Strong use of whitespace
* Smooth animations
* Mobile-first and fully responsive

Use a mostly monochromatic visual system:

* Black
* White
* Off-white
* Soft gray
* Very subtle accent colors only where necessary

Do NOT overuse gradients, glassmorphism, excessive rounded cards, or flashy UI effects.

The website should look suitable for a serious fashion brand and should be visually impressive enough to use as a client project.

---

# TECH STACK

Use:

* Next.js
* React
* TypeScript
* Tailwind CSS
* Modern component architecture
* Lucide React icons
* Framer Motion for tasteful animations
* Use clean reusable components
* Use responsive CSS throughout

Structure the application so it can later be connected to a real backend/database and payment gateway.
